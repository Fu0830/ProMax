# 🎄 圣诞贺卡工坊 by 小鱼 · ProMax

一个单文件 HTML 圣诞贺卡定制网页：

- **信封拆信开场**：闭合信封 + 金色火漆印，点击后封印脱落 → 盖翻开 → 卡片从信中升起，进入贺卡
- **星尘螺旋粒子圣诞树**：黑紫星空背景，紫白星尘螺旋环绕成锥形，顶部闪光星 + 地面星河涟漪
- 8 项颜色自由调节（星云主色 / 高光粒子 / 星尘闪光 / 顶星 / 雾气光晕 / 标题描边 / 夜色 / 卡底），内置 5 套预设配色
- 自定义收件人、标题、祝福文案、署名与日期
- 一键保存封面 / 内页高清 PNG
- **合上贺卡**：卡片阶段可一键合上，反向动画回到未拆信封状态；背景音乐循环播放
- **封面双头像位**：圣诞树左右各一个圆形头像位，可上传任意图片（自动裁成圆形），下方配 1–4 字名字；不预置默认头像
- **内页主题色圣诞树**：信纸上的星光树与主题主色同色，带柔和光晕，换配色自动跟随
- 一键录制「信封开场 → 卡片出现 → 翻卡动画」完整 10 秒视频，自动合成内嵌圣诞背景音乐并自动下载，同时在内嵌播放器预览；收件人、署名留空时对应行不显示

## 本地使用

直接用浏览器打开 `index.html` 即可，无需构建与依赖。建议用 Chrome / Edge 录制视频。

## 技术说明

原生 HTML + CSS + Canvas 2D + 原生 JavaScript，无第三方运行时库；背景音乐以 base64 内嵌；字体走自托管镜像。
